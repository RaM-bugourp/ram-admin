## 二、Bug 修复

### 2.1 登录跳转失败（核心 Bug）

**根因**：`stores/user.ts` 的 `login` action 中 `client.post('/auth/login/')` 未 `await`，`LoginView.vue` 中 `store.dispatch` 也未 `await`。导致 `router.push('/dashboard')` 在 store 状态更新前执行，路由守卫 `isAuthenticated` 返回 false，跳回 `/login`。

**修复**：
- `stores/user.ts`：`login` action 内 `await client.post()` 
- `LoginView.vue`：`handleLogin` 中 `await store.dispatch()`

### 2.2 表单提交刷新页面

**根因**：Arco Design `<a-form @submit="handleLogin">` 中 async handler 未显式调用 `ev.preventDefault()`，浏览器原生表单提交行为触发硬刷新。

**修复**：`LoginView.vue` 接收 `(values, ev)` 并调用 `ev?.preventDefault()`。

### 2.3 401 拦截器无限递归

**根因**：`client.ts` 的 401 响应拦截器调用 `store.dispatch('user/logout')` 后跳 `/login`，但 `logout` 的 HTTP 请求也可能触发 401，导致递归。

**修复**：添加 `isLoggingOut` 互斥锁，`logout` 过程中直接放行不重试。

### 2.4 TypeScript 构建错误

| 错误 | 修复 |
|------|------|
| `IconBell` 不存在于 Arco Design 2.56 | → `IconNotification` |
| `AIAnalyzeResponse` 与 `ai.ts` 中重名 | → 独立 interface 声明 |
| `AIApprovalView.vue` 中 `<a-form>` 缺少 `:model` | → 改为 `<div>` |
| `MainLayout.vue` 中间接引用 `IconBell` 错误 | → `IconNotification` |
